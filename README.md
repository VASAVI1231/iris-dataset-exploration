# Iris Dataset Exploration Using Python & Pandas

## Project Overview

This project focuses on exploring the Iris dataset using Python and Pandas.

The main objective is to understand the structure, dimensions, data types,
statistical characteristics, and basic patterns of a dataset before applying
machine learning models.

## Objectives

- Explore the dataset structure
- Find the number of rows and columns
- Identify column names
- Check data types and missing values
- Generate descriptive statistics
- Display the first and last records
- Identify numerical and categorical columns
- Understand the distribution of Iris species

## Dataset

The Iris dataset contains 150 observations of Iris flowers.

It contains four numerical measurements:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

The target variable contains three species:

- Setosa
- Versicolor
- Virginica

## Technologies Used

- Python
- Pandas
- Scikit-learn
- Jupyter Notebook / Google Colab

## Key Observations

1. The dataset contains 150 rows and 5 columns.
2. Four columns contain numerical flower measurements.
3. The dataset contains three Iris species.
4. The original dataset contains no missing values.
5. Petal measurements provide useful differences between species.

## Conclusion

Dataset exploration is an important step before machine learning.
It helps understand the structure, quality, dimensions and statistical
characteristics of the data.

This project demonstrates basic dataset exploration using Python and Pandas.
